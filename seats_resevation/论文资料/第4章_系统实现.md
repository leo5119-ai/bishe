## 4.2 云函数实现

云函数是本系统的业务逻辑核心，运行在云端Node.js环境中。本系统共开发部署了12个云函数，通过wx.cloud.callFunction()从前端调用。各云函数独立实现特定功能，包括用户身份认证、预约业务处理、座位状态管理、数据初始化等。以下详细介绍核心云函数的实现思路与关键代码片段。

getOpenId是最基础的云函数，用于获取用户的微信openid。openid是用户在微信生态中的唯一标识，是本系统用户身份认证的基础。

**关键代码片段：**

```javascript
// cloudfunctions/getOpenId/index.js
```

### 4.2.2 createReservation云函数

createReservation云函数负责创建新的预约记录，是系统最核心的云函数之一。该函数实现了十项校验逻辑：参数完整性校验、时间格式校验、时间粒度校验（10分钟倍数）、最长时长校验（≤3小时）、座位存在性校验、座位状态校验、时段冲突检测、信用分校验（≥20分）、用户自身冲突检测、预约记录创建。

**关键代码片段：**

```javascript
// cloudfunctions/createReservation/index.js
const MIN_GRANULARITY_MINUTES = 10;  // 时间粒度10分钟

// 时间格式解析
const [sh, sm] = startTime.split(":").map(Number);
const [eh, em] = endTime.split(":").map(Number);
const durationMinutes = (eh * 60 + em) - (sh * 60 + sm);

// 校验：时长必须为10分钟的倍数
if (durationMinutes % MIN_GRANULARITY_MINUTES !== 0) {
  return { success: false, message: "预约时间必须为10分钟的倍数" };
}

// 座位时段冲突检测（区间重叠算法）
const conflictQuery = await db.collection("reservations").where({
  seatId, date, status: _.in(["pending", "checked"])
}).get();

for (const res of conflictQuery.data) {
  const [rs, re] = [res.startTime, res.endTime].map(t => {
    const [h, m] = t.split(":").map(Number);
    return h * 60 + m;
  });
  // 冲突条件：新时段[A,B]与已有时段[C,D]重叠 → A < D 且 B > C
  if (!(endMinutes <= rs || startMinutes >= re)) {
    return { success: false, message: "该时间段已被预约" };
  }
}
```

**说明：** 上述代码展示了createReservation云函数的两项核心校验——时间粒度校验与时段冲突检测。时间粒度校验确保预约时长为10分钟的整数倍；冲突检测采用经典的区间重叠判断算法：对于时段[A, B]（本预约）和[C, D]（已有预约），重叠条件为A < D且B > C，即本预约的结束时间晚于已有预约的开始时间，且本预约的开始时间早于已有预约的结束时间。完整十项校验逻辑及数据库操作代码见附录A.2。

### 4.2.3 checkIn云函数

checkIn云函数负责处理用户签到操作，并根据签到时间判断是否迟到。

**关键代码片段：**

```javascript
// cloudfunctions/checkIn/index.js
const CREDIT_REWARD_CHECKIN = 10;
const CREDIT_PENALTY_LATE = 10;
const LATE_THRESHOLD_MINUTES = 15;

// 计算迟到时间
const nowMinutes = now.getHours() * 60 + now.getMinutes();
const [sh, sm] = reservation.startTime.split(":").map(Number);
const lateMinutes = nowMinutes - (sh * 60 + sm);

// 迟到判定：超过15分钟则预约过期
let creditChange = CREDIT_REWARD_CHECKIN;
let newStatus = "checked";
if (lateMinutes > LATE_THRESHOLD_MINUTES) {
  newStatus = "expired";
  creditChange = -CREDIT_PENALTY_LATE;
}

// 更新预约状态与信用分
await db.collection("reservations").where({ _id: reservationId }).update({
  data: { status: newStatus, creditChange }
});
await db.collection("users").where({ openid }).update({
  data: { credit: Math.max(0, Math.min(100, user.credit + creditChange)) }
});
```

**说明：** 签到时计算当前时间与预约开始时间的差值，若超过15分钟则判定为迟到，将预约状态改为expired并扣除10分信用分；按时签到（≤15分钟）则奖励10分。信用分范围限制在0-100之间。完整签到逻辑及数据库操作代码见附录A.2。

### 4.2.4 autoExpireReservations云函数

autoExpireReservations云函数负责自动处理超时未签到的预约。该函数在用户进入首页时触发，确保过期预约被及时清理。

**关键代码片段：**

```javascript
// cloudfunctions/autoExpireReservations/index.js
const CREDIT_PENALTY_NO_SHOW = 10;

// 北京时间转换
const currentMinutes = (now.getHours() + 8) * 60 + now.getMinutes() % (24 * 60);

// 处理pending状态超时预约（超过结束时间未签到）
const pendingRes = await db.collection("reservations")
  .where({ date: today, status: "pending" }).get();

for (const res of pendingRes.data) {
  const [eh, em] = res.endTime.split(":").map(Number);
  const endMinutes = eh * 60 + em;
  if (currentMinutes > endMinutes) {
    await db.collection("reservations").where({ _id: res._id }).update({
      data: { status: "expired", creditChange: -CREDIT_PENALTY_NO_SHOW }
    });
    await db.collection("users").where({ openid: res.userOpenid }).update({
      data: { credit: Math.max(0, user.credit - CREDIT_PENALTY_NO_SHOW) }
    });
  }
}
```

**说明：** 该函数遍历当日所有pending状态的预约，若当前时间已超过预约结束时间仍未签到，则将状态改为expired并扣除10分信用分。同时处理checked状态预约的超时自动结束。完整自动过期处理逻辑见附录A.2。

## 4.3 核心页面实现

本系统共设计7个核心页面，均基于Vant Weapp组件库构建。各页面通过wx.cloud API与云函数通信，实现前后端分离的轻量化架构。以下详细介绍各核心页面的实现思路与关键代码片段。

### 4.3.1 首页实现

首页（pages/index/index.js）是用户打开小程序后的第一个页面，承担着信息展示与功能导航的作用。

**核心代码片段：**

```javascript
// pages/index/index.js
async initCloud() {
  // 1. 获取openid
  const res = await wx.cloud.callFunction({ name: "getOpenId" });
  this.setData({ openid: res.result.openid });
  
  // 2. 确保用户存在（自动注册）
  const userRes = await db.collection("users").where({ openid }).get();
  if (userRes.data.length === 0) {
    await db.collection("users").add({
      data: { openid, nickName: "新读者", role: "user", credit: 100, createTime: Date.now() }
    });
  }
  
  // 3. 加载今日统计数据
  const seatsRes = await wx.cloud.callFunction({ name: "getAllSeats" });
  const allSeats = seatsRes.result.data || [];
  const reservationRes = await db.collection("reservations")
    .where({ date: today, status: db.command.in(["pending", "checked"]) }).count();
  const rate = Math.round((reservationRes.total / allSeats.length) * 100);
  this.setData({ todayStats: { availableSeats: allSeats.length - reservationRes.total, occupiedRate: rate + "%" } });
}
```

**说明：** 首页在初始化时自动完成四项核心操作：获取用户openid→自动注册新用户→触发自动过期检测→加载今日统计。首页实现了"无感登录"，用户无需手动操作即可使用系统。统计数据包括空闲座位数、今日预约数、使用率，通过座位总数减去预约数计算得出。

### 4.3.2 楼层平面图实现

楼层平面图页面（pages/floor-plan/floor-plan.js）以绝对定位方式渲染座位布局，支持座位状态可视化展示。

**核心代码片段：**

```javascript
// pages/floor-plan/floor-plan.js
// 座位状态优先级：维护中 > 我的预约 > 已占用 > 空闲
updateSeatStatuses() {
  const { currentSeats, occupiedIds, myReservedIds, maintenanceIds } = this.data;
  const updatedSeats = currentSeats.map(seat => {
    let seatStatus = "available";
    if (maintenanceIds.includes(seat.id)) seatStatus = "maintenance";
    else if (myReservedIds.includes(seat.id)) seatStatus = "mine";
    else if (occupiedIds.includes(seat.id)) seatStatus = "occupied";
    return { ...seat, seatStatus };
  });
  this.setData({ currentSeats: updatedSeats });
}

// 点击座位处理
onSeatTap(e) {
  const { id, status } = e.currentTarget.dataset;
  if (status === "available") {
    wx.navigateTo({ url: `/pages/reservation-detail/reservation-detail?seatId=${id}&floor=${this.data.floor}` });
  }
}
```

**说明：** 楼层平面图的核心逻辑是座位状态管理。通过加载当日预约数据，筛选出当前用户预约的座位（mine）、所有被预约的座位（occupied）、维护中的座位（maintenance），其余为可预约座位（available）。状态优先级为：维护中 > 我的预约 > 已占用 > 空闲。点击空闲座位跳转到预约详情页；点击已预约座位显示提示；点击我的预约座位跳转到我的预约页。

### 4.3.3 预约详情页实现

预约详情页（pages/reservation-detail/reservation-detail.js）实现30分钟内时间选择与实时冲突检测。

**核心代码片段：**

```javascript
// pages/reservation-detail/reservation-detail.js
// 生成30分钟内时间选项（5分钟粒度）
setMinStartTime() {
  const now = new Date();
  const currentMinutes = now.getHours() * 60 + now.getMinutes();
  const minMinutes = Math.ceil(currentMinutes / 5) * 5;  // 向上5分钟取整
  const maxMinutes = minMinutes + 30;  // 30分钟内可选
  
  const timeOptions = [];
  for (let m = minMinutes; m <= maxMinutes; m += 5) {
    timeOptions.push(`${String(Math.floor(m/60)).padStart(2,'0')}:${String(m%60).padStart(2,'0')}`);
  }
  this.setData({ startTimeColumns: timeOptions });
}

// 实时冲突检测
checkConflict(start, end) {
  const startMinutes = start.split(":").map(Number).reduce((a,b) => a*60+b);
  const endMinutes = end.split(":").map(Number).reduce((a,b) => a*60+b);
  for (const slot of this.data.occupiedSlots) {
    const slotStart = slot.start.split(":").map(Number).reduce((a,b) => a*60+b);
    const slotEnd = slot.end.split(":").map(Number).reduce((a,b) => a*60+b);
    if (!(endMinutes <= slotStart || startMinutes >= slotEnd)) {
      return `该时段与 ${slot.start}-${slot.end} 的预约冲突`;
    }
  }
  return "";
}
```

**说明：** 时间选择器生成进入页面时刻起30分钟内的可选时间，粒度为5分钟。冲突检测采用区间重叠算法：时段[A,B]与[C,D]重叠的条件是A < D且B > C，即新时段的结束时间晚于已有时段的开始时间，且新时段的开始时间早于已有时段的结束时间。前端实时检测避免无效提交，云函数createReservation中再次校验确保一致性。

### 4.3.4 我的预约页实现

我的预约页（pages/myReservations/index.js）实现签到、取消、结束使用等核心操作。

**核心代码片段：**

```javascript
// pages/myReservations/index.js
// 扫码签到
async onCheckIn() {
  wx.scanCode({
    onlyFromCamera: true,
    success: (res) => {
      if (res.result.includes("library_checkin")) {
        const pendingRes = this.data.todayReservations.filter(r => r.statusLabel === "待签到");
        if (pendingRes.length > 0) this.doCheckIn(pendingRes[0]._id);
      }
    }
  });
}

// 确认签到
async doCheckIn(reservationId) {
  const result = await wx.cloud.callFunction({
    name: "checkIn",
    data: { openid: this.data.openid, reservationId, action: "checkin" }
  });
  if (result.result.success) {
    wx.showModal({ title: "签到成功", content: result.result.message });
    await this.loadReservations();
  }
}

// 结束使用
async onEndUse(e) {
  const result = await wx.cloud.callFunction({
    name: "endReservation",
    data: { openid: this.data.openid, reservationId: e.currentTarget.dataset.id }
  });
  if (result.result.success) {
    wx.showToast({ title: "已结束使用", icon: "success" });
    await this.loadReservations();
  }
}
```

**说明：** 签到支持两种方式：扫描签到二维码或点击卡片按钮直接签到。扫码签到时校验二维码内容包含"library_checkin"标识，匹配成功后调用checkIn云函数。结束使用调用endReservation云函数，将预约状态改为ended，座位状态恢复available供他人预约。操作完成后重新加载预约列表刷新页面状态。

```javascript
  const consecutiveRes = await db.collection("reservations")
    .where({ userOpenid: openid, status: "checked" })
    .orderBy("checkinTime", "desc").limit(30).get();
  
  let consecutiveDays = 0;
  const uniqueDates = [...new Set(consecutiveRes.data.map(r => r.date))].sort().reverse();
  const today = new Date().toISOString().split("T")[0];
  let checkDate = today;
  
  for (const date of uniqueDates) {
    if (date === checkDate) { consecutiveDays++; checkDate = getPrevDate(checkDate); }
    else break;
  }
  this.setData({ consecutiveDays });
}
```
